# Mari 6.0 — Release Notes

**Released:** 2022-12-14 (originally posted 2022-09-20 for public alpha, updated for final release)
**Type:** Stable

## Added
- **Roller Brush** — paints seamlessly repeating detail that follows a brush stroke path.
- **USD material authoring**: artists can now author USD materials using Arnold or RenderMan shaders directly in Mari.

## Changed
- **VFX Reference Platform CY2022 compliance.**
- **Licensing: perpetual licenses discontinued for new Mari purchases** — new licenses are subscription-only from this release forward. Mari Individual: $68/month or $689/year. Team subscriptions: $1,119/year. (This mirrors Foundry's earlier Modo/Katana subscription-only moves and precedes Nuke's own subscription-only cutover in January 2023.)

## Breaking Changes & Migration Notes
- **What breaks:** Guides describing a one-time perpetual Mari purchase no longer reflect how *new* seats are bought from this release on.
  **Workaround:** New seats are subscription-only; existing perpetual licenses from before this change continue to function under their original terms.
